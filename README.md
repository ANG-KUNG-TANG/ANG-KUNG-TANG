### 🤖 AI Study Assistant

**Full-Stack AI-Powered Learning Platform**

`Next.js` · `TypeScript` · `React` · `MongoDB` · `Redis` · `AI`

A full-stack learning platform that helps students study more effectively through AI-powered learning tools.

- Developed a document-based learning workflow for summaries, concepts, flashcards, and quizzes.
- Built application features using Next.js, React, and TypeScript.
- Integrated MongoDB for persistent application data.
- Used Redis for caching and background job infrastructure.
- Designed AI-powered learning workflows with evidence-grounded content.
- Built a Telegram bot integration for interacting with the platform.
- Deployed the application using Vercel.

🔗 **Live Demo:** https://ai-study-ass.vercel.app

🔗 **Repository:** https://github.com/ANG-KUNG-TANG/ai-study-ass
